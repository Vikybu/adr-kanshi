choisir-base-de-donnée.md

Contexte
Pour le projet, il y a besoin d’une base de donnée qui puisse gérer facilement les relations complexes qu’il y a avoir entre les différentes tables.

 Décision
Nous utiliserons postgreSQL est puissant pour les bases de données avec beaucoup de données et qui gèrent des BDD avec des relations complexes.

Alternative considéré
mySQL : fonctionnerait pour le début du projet, mais perte de performance à partir du moment ou le projet va prendre de l'ampleur.
